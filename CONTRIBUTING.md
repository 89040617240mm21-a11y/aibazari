# Contributing · Как предложить улучшение

Everyone is welcome — developers, designers, translators, lawyers, ordinary users.

## Ideas
- Small idea or bug → [Issue](../../issues/new/choose)
- Big idea, new direction, "what if…" → [Discussions](../../discussions)

## Code
1. Fork the repo, create a branch `feature/<short-name>`.
2. Keep pull requests small: one change — one PR.
3. Describe **what** and **why** in the PR; add a screenshot for UI changes.
4. Never commit secrets (tokens, keys, passwords, personal data). PRs with secrets are closed.

## How changes get in
1. An AI review (Claude) checks every PR within a day: security, bugs, fit with the concept.
2. A maintainer merges. Texts, translations and small fixes go in fast — usually the same day.
3. Merged changes are deployed to aibazari.com automatically.

Pull requests that add tracking, ads without consent, paid walls for basic features,
or weaken privacy/safety rules from [docs/CONCEPT.md](docs/CONCEPT.md) will not be accepted.

By contributing you agree your work is published under [AGPL-3.0](LICENSE).

---

По-русски: идеи — в Issues и Discussions, код — через pull request в отдельной ветке. Каждую правку сначала проверяет ИИ, потом принимает мейнтейнер; тексты и переводы — в тот же день. Секреты и личные данные в код не класть.
