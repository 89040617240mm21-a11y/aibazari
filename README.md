# AIbazari

**Free help for everyone, run by AI.** · **Бесплатная помощь всем — под управлением ИИ.**

AIbazari is an open, worldwide, free platform where people exchange what they have and what they need:
things, services, work, help, rides, knowledge. You just write to our Telegram bot in your own words
(or by voice, with a photo) — the AI turns it into a clean listing, translates it, finds matches and keeps scammers out.

> Things that used to cost money because someone had to pay middlemen, moderators and developers —
> AI can now do for free. This project is our attempt to prove it.

## What you can do (planned)

| | Direction | Example |
|---|---|---|
| 🛒 | Sell / buy things | «Selling a bike, Tbilisi, 300 GEL» |
| 🎁 | Give away / donate | «Free baby clothes, pick up today» |
| 🆘 | Ask for help | «Need a ride to the hospital on Monday» |
| 🛠 | Services & specialists | «Plumber, Yerevan, today» |
| 💼 | Jobs | «Looking for a cook, Batumi» |
| 🚗 | Rides & delivery | «Going Moscow → Kazan Friday, 2 seats» |
| 📚 | Learning | «Teach me Excel, I teach English» |
| 🧭 | Travel & leisure | «Who's hiking Kazbek in May?» |
